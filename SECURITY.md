# Security Policy

## Supported versions

Security updates apply to the latest released version on the default branch until a versioning policy is published.

## Reporting a vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

Please report vulnerabilities privately by emailing **security@example.com** (placeholder — replace before launch) or via GitHub Security Advisories once enabled.

Include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Any suggested remediation

We will acknowledge receipt within 5 business days and provide a remediation timeline when possible.
